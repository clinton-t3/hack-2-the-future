# Streamlit Application

## Description
This project is an interactive web application developed using Streamlit and Python.
The application was created for Hack 2 the Future hackathon.
The track selected was the business-track


## Installation
Make sure you have the following installed:
- Python 3.9 or later
- pip, pandas, streamlit

1. Clone the repository:

```bash
git clone (https://github.com/clinton-t3/hack-2-the-future.git)
```

2. Navigate to the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```


## Running the Application

Run the following command from the project directory:

```bash
streamlit run app.py
```

The application should automatically open in your web browser.
Add the files provided by the organizers in the app to get it running.


## Stopping the Application

To stop the application, press `Ctrl + C` in your terminal.
